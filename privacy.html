Privacy Policy — The Home Organizer

Last updated: 5 November 2026. Contact: leowelton771@gmail.com

Who we are

The Home Organizer is a DIY home organization ideas project. This website is its company website. Our Pinterest profile is thehomeorganizerdaily.

What the Pinterest app does

The Home Organizer Pinterest app exists for one purpose only: to publish pins, created by The Home Organizer, to The Home Organizer's own Pinterest boards, using Pinterest's official API (API v5).

Specifically, the app:

  • Uses OAuth 2.0 only. The account owner signs in on Pinterest's own authorization screen and grants the app permission. The app never asks for, stores, or uses a Pinterest password.
  • Requests only these scopes: boards:read, boards:write, pins:read, pins:write.
  • Reads the owner's own boards (to find the board ID for the board the owner chose) and creates pins on those boards, with a title, description, link and image or video the owner supplied.
  • Is used only for The Home Organizer's own account. It is not offered to other users and does not publish on anyone else's account.

What the app does NOT do

  • It does not collect passwords, cookies, or login credentials of any kind.
  • It does not scrape Pinterest, does not automate the Pinterest website, and does not bypass any Pinterest login or security check.
  • It does not collect, store, or sell personal data about visitors, followers, or any other Pinterest user.
  • It does not sell data to anyone, and it does not share data with advertisers.
  • It does not track visitors to this website. This website sets no analytics cookies and no advertising cookies.

Data the app holds

To work, the app holds only: the OAuth access token and refresh token for The Home Organizer's own Pinterest account (held by the account owner, used only to call the Pinterest API on that account's behalf), the board ID the owner chose, and the pin content (title, description, link, image/video file) the owner supplied for publishing. Tokens are never shared with any other party.

Amazon Associates disclosure

Some pins link to Amazon product pages as an Amazon Associate. Where they do, the pin states: “As an Amazon Associate I earn from qualifying purchases.”
